# Cambios en Motoroll Home 2.0

- Rehecha la pantalla de inicio para que parezca un launcher y no un panel de accesos.
- Se añadió un escritorio con reloj y fecha grandes, tarjeta de marca, buscador y cuadrícula de apps.
- Se rediseñó el dock con iconos de las aplicaciones instaladas.
- Se mantiene el cajón de aplicaciones con filtrado en el dispositivo.
- Se sustituyó el tratamiento visual por una paleta negra, azul y violeta propia.
- Se eliminaron tarjetas de acceso rápido que daban aspecto de panel de ajustes.
- Se mantiene el paquete `com.motoroll.home` para actualizar la app anterior.
- Sin servicios persistentes, fondos animados, blur ni dependencias externas.
